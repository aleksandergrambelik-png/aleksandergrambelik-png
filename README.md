# SanderShield 🛡️

[![SanderShield](https://github.com/aleksandergrambelik-png/SanderShield/actions/workflows/audit.yml/badge.svg)](https://github.com/aleksandergrambelik-png/SanderShield/actions/workflows/audit.yml)
[![License](https://img.shields.io/badge/license-GPL--3.0-green)](https://github.com/aleksandergrambelik-png/SanderShield)
[![Platform](https://img.shields.io/badge/platform-Termux%20%7C%20Linux%20%7C%20Windows-orange)](https://github.com/aleksandergrambelik-png/SanderShield)

Mobile-first defensive security toolkit for hardening, filtering, and quick triage in hostile environments.

## What I built

- Fast traffic filtering and anomaly detection
- Privacy and sensor exposure checks
- CVE / vulnerability validation flow
- Quick service exposure scoring
- Lightweight CLI tooling for mobile and Linux environments
